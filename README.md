# BookingApp

Mobile app to search and book professional services (Plumbers, Electricians, Painters, etc.).

Developed with: **React Native** and **React Navigation**

---

## Current Features
- **Auth Module:** Welcome, signup, and login screens.
- **Main Dashboard:** Native search bar with floating bottom tab navigation.
- **Category Search:** Dynamic filtering of professionals through chip components.
- **Professional Detail:** Optimized view matching Material Design guidelines with a direct booking link.
- **Booking Flow:** Interactive date and time picker deployed in a native modal format.
